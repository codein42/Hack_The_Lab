# Hack_The_Lab
perschmann braunschweig hackathon

## Folders
| Folder | What |
|---|---|
| `data/` | raw DB export (parquet, git-ignored) |
| `src/`, `build_features.py` | cleaning, profiles, embeddings, features (see PIPELINE.md) |
| `build/`, `features/`, `vectordb/` | generated tables (git-ignored) |
| `forecast_data_2027/` | Challenge 1 capacity forecast per lab and week |
| `challenge2_model/` | Challenge 2 churn/volume model, forecast + charts (see its `extra/README.md`) |
| `website/` | **Lab Planner** dashboard for Admin + Sales (see `website/README.md`) |
| `knowledge/` | glossary, challenge text, capacity rules (fed into the vector search) |
| `docs/` | challenge brief photos, screencast |
